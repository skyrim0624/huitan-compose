# HuiTan Compose

灰谈个案公共化编辑器。这个 Codex skill 用于把灰谈、大灰咨询、访谈转写、提问者背景和上下文材料，整理成可公开发布的中文公共案例文章。

## 用途

- 从具体个案中提炼公共议题
- 将对话转写改写为栏目文章
- 生成个案卡、角度选项、调研清单、文章结构、初稿和编辑审查
- 维护灰谈系列的文风、口吻和发布排版规则

## 安装

把本目录放入 Codex skills 目录：

```bash
~/.codex/skills/huitan-compose
```

然后在 Codex 中使用：

```text
$huitan-compose
```

## 关键排版规则

访谈整理稿的小标题必须放在本节核心问题之前：

```md
## 2. 社区最值钱的，不是房费

*子扬：* 这个点我能感觉到。我们之前其实也想过不能只靠住宿，但没有定得很清楚。

*大灰：* 社区本身最珍贵的东西，不是房费。
```

不要把小标题夹在提问者追问和大灰回答中间。

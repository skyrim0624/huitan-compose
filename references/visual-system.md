# 灰谈视觉系统

## 最高准则

灰谈的封面图、主视觉、金句图和文中配图必须是“完成图”，不是“底图 + 后贴文字”。

只要图片里出现文字，必须在 Image Generator 生成阶段让文字和画面一起生成。严禁先生成无字底图，再用本地脚本、PIL、Figma、Canva、HTML/CSS 或其他排版方式把文字贴上去。

如果 Image Generator 生成的中文不准确、排版不齐或像后贴字，必须重新生成或减少图中文字；不要用后期排字修补。文字要参与构图、遮挡、留白和材质，成为拼贴、纸片、标签、标题牌、印刷层的一部分，而不是浮在背景上。

判断方法：如果把文字去掉后画面仍像一张完整背景图，或者文字像 PPT 标题压在图上，这张图不合格。

## 图像层级

1. **栏目主视觉 / 封面图**
   - 强栏目识别，允许更密、更有冲击力。
   - 文字必须嵌入标题牌、撕纸、胶带、报纸块或海报块里。
   - 主标题、期数、短副标题要和图像元素形成同一画面，不要在空白处硬排字。

2. **文中配图**
   - 比封面更轻、更留白。
   - 不一定放正文标题文字；如果放文字，也必须是标签、便签、图解节点的一部分。
   - 作用是节奏停顿和理解辅助，不要抢正文。

3. **金句图**
   - 可以更像小海报。
   - 一图只承载一句核心判断。
   - 金句必须像印在纸上、贴在图中或成为海报标题，不要悬浮在画面上。

## 灰谈固定视觉语言

- 黑白波普剪贴、报纸半色调、复古杂志拼贴、撕纸边缘、胶带、手工白描边。
- 强调色以暖黄色为主，少量使用；不要变成大面积黄底。
- 避免蓝紫科技感、赛博渐变、廉价职场焦虑图库感。
- 不使用未经授权的真人照片、头像、家庭细节图。

## 公众号排版原则

- 排版重点是层级，而不是堆视觉组件。
- 标题、小标题、对话块、重点句、图片之间要形成清楚节奏。
- 加粗、浅黄底、引用块只用于问题重构、核心判断和行动建议。
- 图片数量要少，默认一篇长文 1 张封面 + 2-4 张文中图。
- 每张图必须有明确功能：主视觉、章节停顿、逻辑辅助或传播金句。
